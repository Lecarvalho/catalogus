# User docs

Reader-facing documentation for someone with a Catalogus-managed repo who wants to understand or
review its `catalogus.yaml`. The rest of `docs/` — the handoff, the plan, briefs — is internal;
this folder is what an outside reader is pointed at.

- [`manifest-format.md`](manifest-format.md) — the `catalogus.yaml` format: every field, what it
  means, and which CLI command writes it.
